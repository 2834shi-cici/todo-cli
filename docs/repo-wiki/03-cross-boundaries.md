# 跨端边界

todo-cli 是单进程、单端 CLI 工具，**不存在前后端、服务间、monorepo packages 的跨边界交互**。本页说明其与外部系统的唯一边界：文件系统。

## 唯一边界：本地文件系统

- **数据文件**：`~/.todo-cli/data.json` — 唯一的外部持久化介质
  > **源码** `src/storage.ts:6-7`
- **交互方式**：整体读写（无增量更新、无锁、无流式）
  > **源码** `src/storage.ts:27-61`

## 边界特征

| 维度 | 说明 |
|------|------|
| 协议 | 无（直接文件 I/O） |
| 数据格式 | JSON，UTF-8 |
| 并发 | 无（单进程，无锁） |
| 失败模式 | 文件不存在 → 自动创建空仓库；JSON 损坏 → 抛错退出 |

> **源码** `src/storage.ts:40-50`

## 无跨边界内容

本项目不包含以下内容，相关 Wiki 主题不适用：

- API client / DTO / 共享类型（无网络）
- 前后端分界（纯 CLI）
- 多 package 协作（单 package）
